# Ansh Budhiraja
### Backend Software Engineer — Node.js, TypeScript, Cloud Infrastructure

I build backend systems that have to be right — the kind moving money, inventory, and access permissions where a bug means someone's ledger doesn't balance.

Currently at **Sasefied**, building the backend for a multi-tenant supply chain platform: RBAC across warehouse hierarchies, event-driven services on RabbitMQ, and a reconciliation engine spanning Razorpay, Wise, and internal ledgers — plus the Azure infrastructure it runs on.

Before that, at **Code Pulse IT Services**, I ran the technical side of 15+ client engagements solo — architecture through deployment, no handoffs.
